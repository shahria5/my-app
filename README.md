# TextUtils - React Text Analyzer Application

**TextUtils** is a simple yet powerful React-based web application designed to analyze and manipulate text efficiently. It offers various utility tools such as text case conversion, extra space removal, clipboard copying, word/character counting, and estimated reading time calculations.

🚀 **Live Demo:** [https://shahria5.github.io/my-app/](https://shahria5.github.io/my-app/)

---

## ✨ Features

* 🔠 **Convert Case:** Easily convert text to **UPPERCASE** or **lowercase**.
* ✂️ **Remove Extra Spaces:** Clean up unnecessary spaces within your text in one click.
* 📋 **Copy to Clipboard:** Quickly copy formatted text to your clipboard.
* 📊 **Text Summary:** Real-time word count, character count, and estimated reading time calculation.
* 👁️ **Live Preview:** Instant preview of the entered text.
* 🌙 **Dark Mode Toggle:** Smooth dark/light theme switching for comfortable viewing.
* 🔤 **Font Size Control:** Adjust input text area font size dynamically.
